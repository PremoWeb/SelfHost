# Welcome to SelfHost

SelfHost is a powerful, open-source platform designed to give you full control over your infrastructure. Whether you're managing a single server or a multi-cloud cluster, SelfHost provides the tools you need to deploy, monitor, and scale your applications with ease.

## Why SelfHost?

In an era of increasing centralization and rising cloud costs, SelfHost empowers developers and organizations to:

> [!NOTE]
> SelfHost is currently in active development. Features are being added rapidly, and we would love your feedback on our Discord community.

- **Retain Ownership**: Your data, your servers, your rules.
- **Reduce Costs**: Eliminate heavy "platform tax" from managed providers.
- **Simplify Operations**: A unified dashboard for all your infrastructure needs.

## Core Features

### Multi-Cloud Support
Connect with providers like **Vultr**, DigitalOcean, and AWS, or bring your own bare-metal servers.

### Built-in Git Hosting
Each project can have its own Git repository with full support for clone, push, and pull operations over both HTTP and SSH. No need for external Git hosting services.

### Automated Deployments
Streamline your workflow with Git-integrated pipelines and Docker-based containerization.

### Advanced Security
Manage SSH keys, API tokens, and private repositories with industry-standard encryption.

### Comprehensive Audit Logging
Track every action taken in the UI with detailed logs including user context, impersonation state, and request details. Perfect for security auditing and debugging.
